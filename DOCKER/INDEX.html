Conceito core

A Trindade do Docker

Todo workflow Docker segue este fluxo de 3 etapas. Clique em cada etapa para explorar.

PASSO 01
📄 Dockerfile
A "receita de bolo". Um arquivo de texto com todas as instruções para montar sua imagem.
FROM node:18 WORKDIR /app COPY . . RUN npm install CMD ["npm","start"]
→
PASSO 02
📦 Imagem
O "bolo congelado". Um pacote estático, pronto para ser distribuído e executado em qualquer lugar.
$ docker build -t meu-app . Step 1/5 : FROM node:18 ✓ Step 2/5 : WORKDIR /app ✓ ... Successfully built 4a8f9b2
→
PASSO 03
🚀 Container
O "bolo servido". A instância em execução da sua imagem. Você pode ter vários ao mesmo tempo!
$ docker run -p 3000:3000 meu-app > Server running on port 3000 ✓ Container ID: 7f3c91a...
